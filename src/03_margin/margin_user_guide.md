## 1. 이 도구로 할 수 있는 일

한 화면에서 **제조원가 → 수출 단가 → 바이어 역제안 대응 → 수량별 가격표 → 환율 리스크 → 견적서 PDF · 영문 메일**까지 끝냅니다.

| 하고 싶은 일 | 어디서 | 걸리는 시간 |
|---|---|---|
| 품목 원가·물류비를 불러와 FOB 단가 뽑기 | 좌측 **ERP 연동** → **견적 계산** 탭 | 10초 |
| 바이어가 제시한 가격을 받아도 되는지 판단 | **역제안 분석** 탭 | 30초 |
| 수량별 가격표(3천 / 5천 / 1만 / 2만 / 5만개) 만들기 | **수량별 단가** 탭 | 1분 |
| 결제 시점 환율이 떨어지면 얼마 손해인지 확인 | **환율 영향** 탭 | 30초 |
| 회사 양식 견적서 PDF + 바이어 메일 본문 | **견적서 PDF** 팝업 | 2분 |

- 계산은 모두 브라우저에서 즉시 합니다. 값을 하나 바꾸면 **4개 탭이 동시에** 다시 계산됩니다. "계산" 버튼은 없습니다.
- 모든 숫자 칸은 직접 고칠 수 있습니다. ERP·프리셋이 채운 값도 예외가 아닙니다.

## 2. 화면 구성 한눈에 보기

```
┌──────────────────────┬─────────────────────────────────────────────────┐
│ ① 견적 조건 (상단 고정)│ [견적 계산][역제안 분석][수량별 단가][환율 영향]  기준 환율 [1320]원 │
│  주문수량 · 인코텀즈    │                                     TTB 1,351.1 │
│  목표 / 최소 영업마진   ├─────────────────────────────────────────────────┤
│  마진율 ↔ 마크업        │                                                 │
├──────────────────────┤          선택한 탭의 결과 화면                    │
│ ② 제조원가 · 1차 마진  │                                                 │
│  [ERP 연동]  ▸ 원가 합계│                                                 │
├──────────────────────┤                                                 │
│ ③ 물류비  ▸ FOB 물류비 │                                                 │
│   (펼치면 CBM 추정)    │                                                 │
├──────────────────────┤                                                 │
│ 현재 견적 요약 (항상)   │                                                 │
│  FOB 10,000개  $3.74  │                                                 │
└──────────────────────┴─────────────────────────────────────────────────┘
```

| 영역 | 역할 | 기본 상태 |
|---|---|---|
| ① 견적 조건 | 미팅 중 가장 자주 바꾸는 값. 좌측 Card를 스크롤해도 **위에 고정** | 펼침 |
| ② 제조원가 · 1차 마진 | ERP에서 받아오는 원가와 항목별 1차 마진율 | 접힘 (원가 합계와 연동 상태만 표시) |
| ③ 물류비 | FOB 물류비 · 물류 마진 · 해상운임 · 보험 + **약식 포장/CBM 추정** | 접힘 (총액 · CBM · 개당 물류비 요약) |
| 현재 견적 요약 | 단가 · 주문 총액 · 할인 후 영업마진. **어느 탭에 있든 항상 보임** | 항상 표시 |
| 기준 환율 | 모든 USD 환산의 기준. 오른쪽 위 | 실시간 TTB −2% |

> 💡 ②·③은 `▸` 머리를 눌러 펼치고 접습니다. 접힌 상태에서도 요약(원가 합계, `3.14 CBM (209박스) · 개당 47원 · 마진 10.0%`)이 보이므로 미팅 중에는 접어 두세요.

## 3. 5분 빠른 시작 — ERP 연동부터 견적서 PDF까지

처음 쓰는 분은 아래 순서를 그대로 한 번 따라 해 보세요. (시연 품목 `EU-SER-041 세럼 30ml` 기준)

### Step 1. ERP 연동 (10초)

1. 좌측 ② **제조원가 · 1차 마진** 오른쪽의 **[ERP 연동]** 을 누릅니다.
2. 버튼이 잠깐 `불러오는 중`으로 바뀐 뒤 화면 아래에 안내가 뜹니다.
   > ERP에서 [EU-SER-041] 제품의 제조원가 및 표준 물류 프리셋을 불러왔습니다.
3. 아래 값이 한 번에 채워집니다.

| 구분 | 채워지는 값 |
|---|---|
| 견적 조건 | 주문수량 10,000개 · FOB · 목표 영업마진 20% · 최소 영업마진 15% |
| 제조원가 (개당) | 원재료 1,150원(마진 20%) · 임가공 538원(10%) · 부자재 1,485원(15%) · 로스율 3% · 사급 아님 |
| 물류 | 단품 용량/형태 **세럼/앰플 30ml** → 48ea/카톤 · 0.015 CBM → **209박스 · 3.14 CBM** → **FOB 물류비 470,000원 (개당 47원)** · 해상운임 $157 · 물류 마진 10% |
| 견적서 | 품목명(영문) `Serum 30ml` |
| 역제안 | 바이어 목표가 = 연동 후 견적 단가 −5% (첫 역제안 연습용) |

4. 좌측 ② 머리에 `EU-SER-041 세럼 30ml · 14:51 동기화`가 표시됩니다.

### Step 2. 단가 확인 (10초)

- **견적 계산** 탭 상단의 큰 숫자가 FOB 단가입니다. (기준 환율 1,320원이면 **$3.74**)
- 바로 아래 막대로 원가 · 1차 마진 · 물류비 · 물류 마진 · 영업마진 비중을 확인합니다.

### Step 3. 바이어 목표가 판정 (30초)

- **역제안 분석** 탭에서 바이어 목표가 칸에 바이어가 제시한 가격을 넣습니다.
- 판정 박스에 `수락 가능 / 영업마진 양보 / 1차·물류 마진 조정 / 마진만으로 불가` 중 하나와 **승인 필요 수준(R&R Badge)** 이 나옵니다.
  예) ERP 연동 직후 목표가 $3.55 → `영업마진 양보` · `팀장 전결 가능 (승인 권장)` · 영업마진 15.7% · 35원 여유

### Step 4. 견적서 PDF + 메일 (2분)

1. **견적 계산** 탭 › 아래 Card의 **견적서** 탭 › **[견적서 PDF]**
2. 팝업에서 **고객사 회사명(영문)** 만 넣으면 필수값이 끝납니다. (견적 번호·품목명은 자동으로 채워져 있음)
3. **[PDF 다운로드]** → 저장 완료 안내가 뜨면 **[영문 이메일 제안문 복사]** → 메일에 붙여넣기.

끝입니다. 이후 장에서 각 기능을 자세히 설명합니다.

## 4. 좌측 입력 자세히 보기

### 4.1 ① 견적 조건

| 항목 | 설명 | 기본값 |
|---|---|---|
| 주문수량 | 이번 견적 수량(개). 물류비·수량 할인·MOQ 할증이 모두 이 값을 따릅니다 | 10,000 |
| 인코텀즈 | EXW / FOB / CFR / CIF. 바꾸면 단가에 들어가는 비용이 달라집니다 (아래 표) | FOB |
| 목표 영업마진 | 이번 견적에서 남기고 싶은 영업마진 | 20% |
| 최소 영업마진 (방어선) | **최종 판매가 기준으로 절대 밑돌면 안 되는 한계선**. 역제안 판정·승인 Badge·환율 마지노선의 기준 | 15% |
| 마진율 / 마크업 | 마진을 **판매가 대비(마진율)** 로 볼지 **원가 대비(마크업)** 로 볼지. 모든 마진에 공통 적용 | 마진율 |

**인코텀즈별로 단가에 들어가는 것**

| 인코텀즈 | 원가 + 1차 마진 | FOB 물류비 + 물류 마진 | 해상운임 | 보험 |
|---|---|---|---|---|
| EXW | ○ | ✕ (바이어 운송) | ✕ | ✕ |
| FOB | ○ | ○ | ✕ | ✕ |
| CFR | ○ | ○ | ○ | ✕ |
| CIF | ○ | ○ | ○ | ○ (단가 × 110% × 보험요율) |

> 💡 **마진율 vs 마크업**: 같은 20%라도 마진율 20%는 원가 800원 → 1,000원, 마크업 20%는 800원 → 960원입니다. 사내 기준이 "판매가 대비"면 마진율을 쓰세요. 마크업으로 바꾸면 화면의 목표·최소 표시는 판매가 대비로 환산해 보여줍니다(마크업 20% = 판매가 대비 16.7%).

### 4.2 ② 제조원가 · 1차 마진

`▸ 원가 합계`를 눌러 펼치면 세부 항목이 나옵니다.

| 항목 | 설명 |
|---|---|
| 1차 마진 입력: **항목별 / 일괄** | 항목별 = 원재료·임가공·부자재마다 다른 마진율. 일괄 = 세 항목에 같은 마진율 한 칸 |
| 원재료 · 임가공 · 부자재 (개당) | 원 단위 제조원가 |
| 마진율 | 항목별 1차 마진율 |
| 로스율 | 세 원가 항목에 모두 곱해집니다 (예: 3% → 원가 × 1.03) |
| 부자재 사급 | 체크하면 바이어가 부자재를 공급한다고 보고 **부자재 마진을 0%** 로 계산 |

- **원가 합계**는 로스율을 반영한 개당 원가입니다. (ERP 연동 시 3,173원 × 1.03 = **3,268원**)
- **연동 상태 표시**
  - `ERP 미연동 · 예시 값` — 처음 화면. 예시 원가(850 / 400 / 650원)로 계산 중
  - `EU-SER-041 세럼 30ml · 14:51 동기화` — ERP 값 그대로
  - `ERP 값에서 수정됨` (주황) — 세부 원가·마진율·로스율·사급 중 하나라도 직접 고친 상태
- **[ERP 연동]을 다시 누르면** 언제든 ERP 원본 값으로 되돌아갑니다.

> ⚠️ 현재는 **시연 단계**라 ERP 연동이 예시 품목 1개(`EU-SER-041`)만 돌려줍니다. 실제 ERP 연결 후에도 사용 방법은 같습니다.

### 4.3 ③ 물류비와 약식 포장/CBM 추정

`▸ FOB 물류비 총액`을 눌러 펼칩니다.

**위쪽 — 계산에 실제로 쓰이는 칸**

| 항목 | 설명 |
|---|---|
| FOB 물류비 총액 | 공장 → 선적항까지 내륙운송·통관·항만 부대비 **주문 전체 금액**. 수량으로 나눠 개당 물류비가 됩니다. EXW면 0으로 계산 |
| 물류 마진율 | 물류비에 붙이는 마진 |
| 해상운임 총액 ($) | CFR·CIF일 때만 보이고 단가에 더해집니다 |
| 보험요율 | CIF일 때만 보입니다 |

**아래쪽 — 약식 포장/CBM 추정 (ODM 표준 패키징 프리셋)**

1. **단품 용량/형태**를 고르면 카톤당 입수 · 카톤 부피 · 내륙·통관 단가 · LCL 단가가 자동으로 채워집니다.

| 프리셋 | 카톤당 입수 | 카톤 부피 | 10,000개일 때 |
|---|---|---|---|
| 세럼/앰플 30ml | 48 ea | 0.015 CBM | 209박스 · 3.14 CBM · 470,000원 |
| 토너/에센스 100~150ml (기본) | 40 ea | 0.024 CBM | 250박스 · 6.00 CBM · 900,000원 |
| 크림 50ml (단지) | 48 ea | 0.020 CBM | 209박스 · 4.18 CBM · 630,000원 |
| 마스크팩 (10매 세트박스) | 20 세트 (200장) | 0.026 CBM | 500박스 · 13.00 CBM · 1,950,000원 |
| 클렌징 폼/튜브 100~150ml | 50 ea | 0.022 CBM | 200박스 · 4.40 CBM · 660,000원 |

   (내륙·통관 150,000원/CBM · LCL $50/CBM 공통)

2. 계산 방식
   - 카톤 수 = ⌈주문수량 ÷ 카톤당 입수⌉
   - CBM = 카톤 수 × 카톤 부피 (소수 2자리)
   - FOB 내륙물류비 = CBM × 내륙·통관 단가 → **1만원 단위 반올림**
   - 해상운임 = CBM × LCL 단가 → $1 단위 (참고용)
   - 1 CBM 미만은 LCL 관행대로 **최소 1 CBM**으로 계산합니다.
   - 15 CBM 이상이면 "20ft 컨테이너(FCL) 견적과 비교해 보세요" 안내가 나옵니다.

3. **물류비 자동 반영** — 가장 중요한 동작입니다.

| 상황 | FOB 물류비 · 해상운임 칸 |
|---|---|
| 프리셋을 고르거나 ERP 연동을 함 | 자동 반영 **켜짐** → 추정값이 바로 들어가고, 버튼이 `위 물류비·해상운임에 자동 반영 중`으로 바뀜 |
| 자동 반영 중에 주문수량 · 프리셋 · 입수 · 부피 · 단가를 바꿈 | 즉시 다시 계산되어 칸과 오른쪽 탭(개당 물류비·물류 마진)이 함께 바뀜 |
| FOB 물류비나 해상운임 칸에 **직접 숫자를 입력** | **그 칸만** 자동 반영 꺼짐 → 입력한 값이 우선. 수량을 바꿔도 그대로 유지 |
| **[물류비 자동 반영]** 버튼을 누름 | 두 칸 모두 다시 자동 계산으로 연결 |
| 페이지를 처음 열었을 때 | 자동 반영 꺼짐 (예시 값 1,200,000원 · $1,500) |

> 💡 포워더에게 실제 견적을 받았다면 그 금액을 FOB 물류비 칸에 **직접 입력**하세요. 이후 수량을 바꿔도 덮어쓰지 않습니다. 추정치로 돌아가고 싶을 때만 [물류비 자동 반영]을 누르면 됩니다.

### 4.4 기준 환율 (오른쪽 위)

- 모든 USD 단가는 **원화 판매가 ÷ 기준 환율**입니다.
- 페이지를 열면 실시간 USD **TTB(전신환 받으실 때)** 를 조회하고, 칸을 건드리지 않았다면 **TTB × 98%를 10원 단위로 내린 값**을 넣습니다. (TTB 1,351.1 → 1,320원)
  - 이유: 견적~결제 사이 원화가 강세가 되어도 마진이 버티도록 **보수적으로** 잡는 수출 견적 관행입니다.
- 라벨 아래 알약 버튼 `TTB 1,351.1`을 누르면 **실시간 TTB 그대로** 적용됩니다. 같은 값이면 `✓`가 붙습니다.
- 알약에 마우스를 올리면 환율 출처와 기준 시각이, 기준 환율 칸에 올리면 "실시간 TTB보다 몇 원(몇 %) 낮게 잡았는지"가 보입니다.
- TTB는 10분마다 다시 조회하지만, **이미 쓰고 있는 기준 환율을 바꾸지는 않습니다.** (미팅 중 숫자가 갑자기 바뀌지 않도록)

```
현재 견적 · FOB 10,000개                  $3.74
주문 총액 $37,400          할인 후 영업마진 20.0%
```

- 어느 탭에서든 보입니다. 영업마진이 **최소 영업마진 아래로 떨어지면 빨간색**으로 바뀝니다.

## 5. 견적 계산 탭

### 5.1 대표 단가와 단가 구성 막대

- 큰 숫자: 선택한 인코텀즈 기준 **개당 USD 단가**
- 오른쪽: 원화 단가 · 주문 총액, 수량 할인 / MOQ 할증 / MOQ 미달 Badge
- 막대: 원가 · 1차 마진 · 물류비 · 물류 마진 · 영업마진 (· 수량 할인 · 소량 할증). 칸 위 숫자는 원화 금액이고, 막대에 없는 항목은 범례에서도 숨겨집니다.

### 5.2 핵심 지표 4개

| 지표 | 의미 |
|---|---|
| 원가 | 개당 제조원가 (로스 포함) |
| 1차 마진 | 물류 포함 1차 마진율 = 1 − (원가 + 물류비) ÷ 영업 전 공급가 |
| 할인 후 영업마진 | 수량 할인·할증까지 반영한 **실제 영업마진**. 아래에 목표·최소 기준 표시, 최소 미만이면 빨간색 |
| 총 마진 | 판매가 대비 전체 마진 (1차 + 물류 + 영업) |

### 5.3 상세 — 항목별 원가

원재료 · 임가공 · 부자재 · 물류비(개당)의 **원가 / 마진율 / 공급가 / 마진**과 합계. 사급이면 부자재 옆에 `사급` Badge가 붙습니다. 내부 검토·팀장 보고용으로 쓰세요.

### 5.4 상세 — 견적서 (바이어에게 보여줄 형태)

| 형식 | 바이어가 보는 내용 | 이럴 때 |
|---|---|---|
| **통합형** | 품목 1줄, 단가 하나 | 가장 일반적. 원가 구조를 드러내지 않을 때 |
| **분리형** | 제품(EXW) + 내륙 물류 + (해상운임) + (보험) 줄 나눔 | 바이어가 물류비를 따로 보고 싶어 할 때, 인코텀즈 전환 협상 대비 |
| **오픈북형** | 통합 단가 + 개당 원가 구성(제품 원가 · 물류 · 마진 비율) | 오픈북 계약, 원가 투명성을 요구하는 대형 바이어 |

**원가 구성 숨김 / 마진 흡수 발행** (체크 옵션)

- 체크하면 마진 일부를 **원가·물류비에 흡수**시켜 분리형·오픈북형에 보이는 원가를 높이고 마진을 낮게 보이게 합니다. **단가는 그대로**입니다.
- 슬라이더로 원가 / 물류비에 흡수할 금액을 정하고, 원화 / 달러 표시를 바꿀 수 있습니다.
- 아래 **내부 원가표 ↔ 대외 견적** 두 표로 비교합니다.
  - `마진 초과 흡수`(빨강): 흡수액이 총 마진보다 큼 → 줄이세요
  - `원가 +20% 초과`(주황): 원가를 실제보다 20% 넘게 부풀림 → 바이어 검증에 걸릴 위험
- 체크를 해제하면 슬라이더 값은 남아 있지만 계산에는 0원으로 들어갑니다.

## 6. 역제안 분석 탭

바이어가 "이 가격이면 하겠다"고 할 때 **받을지 · 어디까지 양보할지 · 무엇을 다시 제안할지**를 정합니다. 화면은 위에서 아래로 ① 판정 → ② 대응 방안 → ③ 내부 원가 절감 순서입니다.

### 6.1 ① 목표가 입력과 판정

| 입력 | 설명 |
|---|---|
| 바이어 목표가 ($) | 바이어가 제시한 단가. 좌측 인코텀즈 기준으로 입력하세요 |
| 1차 마진 양보 한계치 (항목별) | 원재료·임가공·부자재·물류비 **각각의 1차 마진**을 최대 어디까지 낮출 수 있는지 (기본 5%) |

**판정 4단계**

| 판정 | 조건 | 의미 |
|---|---|---|
| 🟢 수락 가능 | 목표가 ≥ 목표 마진가 | 목표 영업마진 이상 남음 |
| 🟡 영업마진 양보 | 최소 마진가 ≤ 목표가 < 목표 마진가 | 영업마진만 줄이면 됨. 1차·물류 마진은 그대로 |
| 🟠 1차·물류 마진 조정 | 최대 양보가 ≤ 목표가 < 최소 마진가 | 방어선을 지키려면 1차·물류 마진을 깎아야 함 |
| 🔴 마진만으로 불가 | 목표가 < 최대 양보가 | 모든 마진을 한계치까지 줄여도 부족 → 사양·수량·물류 조건을 바꿔야 함 |

**승인 가이드라인 (R&R Badge)** — 목표가에서 남는 영업마진 기준

| 남는 영업마진 | Badge | 진행 |
|---|---|---|
| 목표 이상 | 없음 | 담당자 진행 |
| 최소 ~ 목표 | `팀장 전결 가능 (승인 권장)` | 팀장 보고 |
| 최소 미만 | `본부장/임원 특별 승인 필요 (마진 방어 필수)` | 상위 승인 필요 |

판정 박스에는 영업마진과 함께 **`35원 여유` / `82원 부족`** (방어선 대비 개당 금액)이 표시됩니다.

**가격 위치 Gauge** — 손익분기 · 최대 양보가 · 최소 마진가 · 목표 마진가 눈금 위에 바이어 목표가(말풍선)가 어디에 있는지 보여줍니다. 바이어에게 "왜 이 가격이 어려운지" 설명할 때 화면을 그대로 보여 줘도 됩니다(내부 금액이 드러나니 주의).

### 6.2 ② 대응 방안 (카운터 오퍼)

판정 바로 아래에 바이어에게 다시 제안할 수 있는 선택지가 카드로 나옵니다. 목표가가 최소 마진가보다 낮으면 ①이 강조됩니다.

| 카드 | 내용 |
|---|---|
| 재역제안 | 1차·물류 마진은 그대로, 영업마진만 **최소선**까지 양보한 단가 |
| 1차·물류 마진 일괄 | 바이어 목표가에서 최소 영업마진을 지키려면 1차·물류 마진을 몇 %로 맞춰야 하는지 |
| EXW로 전환 | 물류비·물류 마진을 빼고 바이어가 운송할 때의 단가 (현재 EXW가 아닐 때) |
| ○○개 유도 | 다음 수량 할인 구간까지 주문을 늘리면 되는 단가 (물류비는 수량 비례의 85% 가정) |

### 6.3 ③ 내부 원가 절감 시뮬레이션

목표가를 **꼭** 맞춰야 할 때 쓰는 2차 단계입니다. 두 Card의 결과가 합쳐져 **위 판정·Gauge에 즉시 반영**됩니다. (`영업마진 12.0% → 16.4%`처럼 전후가 함께 표시)

**사양 변경(VE) 추천** — 체크만 하면 됩니다.

| 항목 | 개당 절감 (보수적 하한) |
|---|---|
| 부자재 코팅/후가공 생략 (UV 코팅·박·에폭시 제외) | −30원 (부자재) |
| 단상자 평량·도수 축소 (평량 한 단계 하향, 1도 인쇄) | −20원 (부자재) |
| 원료 등급 대체 (고가 추출물 → 동등 규격 범용 원료) | −40원 (원재료) |

하단에 `선택 절감 개당 −59원 · 주문 전체 약 −588,235원`처럼 요약됩니다. **약식 추정이므로 확정 전 공급사·연구소 확인이 필요합니다.**

**마진 직접 조정** — 원재료 · 임가공 · 부자재 · 물류비의 1차 마진율을 칸에 직접 입력합니다. 바꾼 행은 파란 배경으로 표시되고 행마다 절감 금액이 나옵니다. **[현재값으로]** 를 누르면 조정을 모두 되돌립니다.

> 💡 여기서의 VE 체크·마진 조정은 **시뮬레이션**일 뿐 좌측 입력(실제 견적 조건)을 바꾸지 않습니다. 확정하려면 좌측 ② 제조원가의 값을 직접 고치세요.

## 7. 수량별 단가 탭

바이어에게 보낼 **수량별 가격표**를 만듭니다.

### 7.1 머리 Card — 정책 설정

| 항목 | 설명 | 기본값 |
|---|---|---|
| MOQ | 최소 주문수량 | 5,000개 |
| MOQ 미만 주문 | **소량 할증**(단가에 할증률 가산) / **주문 불가**(표에서 "주문 불가"로 표시, 복사 대상 제외) | 소량 할증 |
| 할증률 | 소량 할증 선택 시만 활성 | 10% |
| 견적 수량 추가 | 수량 입력 후 **[추가]** 또는 **Enter** | - |
| 수량 할인 구간 | `[20,000개] 이상 [3%]` 형태. **[+ 구간 추가]** 로 추가, `×` 로 삭제 | 2만개 3%, 5만개 5% |

- **[+ 구간 추가]** 는 가장 큰 구간의 수량 × 2, 할인율 +2%p로 새 구간을 만듭니다.
- 구간 시작 수량이 가격표에 없으면 **그 수량 행이 자동으로 추가**되어 할인 효과를 바로 확인할 수 있습니다.
- 요약 박스: `MOQ 5,000개부터 $x.xx` · 가장 싼 수량과 단가, MOQ 대비 몇 % 낮은지.

### 7.2 수량별 단가표

| 열 | 내용 |
|---|---|
| 수량 | 편집 가능. MOQ와 같은 수량 옆에 `MOQ` 표시 |
| 물류비 총액 | 편집 가능. 아래에 개당 물류비 |
| 단가 | 가로 막대 + USD 단가. 아래에 `현재 주문` · 할인/할증 · 주문 총액 |
| 영업마진 | 목표·최소 기준 색 Badge (기준은 Card 부제에 표시) |
| × | 행 삭제 (최소 1행 유지) |

- 막대 색: **진한 파랑 = 현재 주문**, 연한 색 = 다른 수량, **빗금 = MOQ 미만**
- **현재 주문 행은 좌측 입력과 연결**되어 있어 견적 계산 탭 단가와 항상 같습니다.
  - 이 행의 물류비를 고치면 → 좌측 FOB 물류비가 바뀝니다 (직접 입력으로 간주되어 자동 반영이 꺼짐)
  - 표에 현재 수량이 없으면 삭제할 수 없는 임시 `현재 주문` 행이 나타납니다. 이 행의 수량을 고치면 좌측 주문수량이 바뀝니다.
- 새로 추가한 행의 물류비는 가장 가까운 수량 행에서 `(수량비)^0.75`로 추정합니다. (수량이 늘수록 개당 물류비가 줄어드는 관행을 반영한 약식) 실제 견적이 있으면 덮어쓰세요.

## 8. 환율 영향 탭

"계약은 달러로 했는데 결제받을 때 환율이 떨어지면?"을 확인합니다.

### 8.1 입력

| 항목 | 설명 |
|---|---|
| 계약 단가 (USD 고정) | 기본은 **현재 견적 단가 사용**(체크). 체크를 풀면 이미 계약한 단가를 직접 입력 |
| 결제 시점 환율 | 숫자 입력 또는 슬라이더 (서로 연동). **[견적 환율로]** 로 기준 환율 복귀 |

- 슬라이더 범위는 기준 환율 ±10%(최소·목표 마진 환율이 밖이면 최대 ±20%까지 넓힘)입니다.
- **슬라이더 트랙 색**이 곧 위험 지도입니다: 빨강 = 최소 마진 미달 / 주황 = 최소~목표 / 초록 = 목표 이상.

### 8.2 결과

| 결과 | 의미 |
|---|---|
| 실현 영업마진 | 그 환율로 결제받을 때 실제 영업마진 + 판정 Badge (목표 마진 유지 / 최소 마진 이상 / 최소 마진 미달 / 영업 손실) |
| 환차손익 (주문 전체) | 견적 환율 대비 이익 ▲(빨강) / 손실 ▼(파랑). 아래에 개당 금액 |
| 방어 단가 | 그 환율에서도 **목표 영업마진을 지키려면 바이어에게 요구해야 할 USD 단가** |
| 마지노선 환율 칩 | 손익분기 · 최소 마진 · 목표 마진을 지키는 **최저 환율**. 견적 환율에서 이미 미달이면 빨간 숫자 |

### 8.3 환율 변동 시나리오 표

견적 환율 대비 −10% / −5% / 0 / +5% / +10%에서 환율 · 개당 원화 · 영업마진(Badge) · 주문 영업이익을 한 표로 보여줍니다. 팀장 보고 자료에 그대로 옮기기 좋습니다.

## 9. 견적서 PDF · 영문 이메일 제안문

### 9.1 팝업 열기

### 10.1 미팅 전 (준비 10분)

|---|---|---|

### 10.2 미팅 중 (실시간 대응)

- **좌측 ① 견적 조건만 만지세요.** 수량·인코텀즈·마진을 바꾸면 모든 탭이 즉시 반영되고, 좌측 맨 아래 **현재 견적 요약**에서 단가·총액·영업마진을 바로 읽을 수 있어 탭을 오갈 필요가 없습니다.

- 권한 밖(`본부장/임원 특별 승인 필요`)이면 → **대응 방안** 카드에서 `○○개 유도` 또는 `EXW로 전환`을 먼저 제시.
- 수량을 늘리자는 대화가 나오면 → 좌측 주문수량만 바꾸세요. 자동 반영 중이면 물류비(카톤 수·CBM)까지 따라 바뀝니다.
- "CIF로 주세요" → 좌측 인코텀즈를 CIF로 바꾸고 ③에서 해상운임·보험요율 확인. 자동 반영 중이면 해상운임이 CBM 기준으로 채워져 있습니다.

1. 최종 조건으로 좌측 입력 확정 (역제안 탭의 VE·마진 조정은 시뮬레이션일 뿐이니, 채택했다면 좌측 ②에 반영)
2. **견적서** 탭에서 형식 선택 → **[견적서 PDF]** → PDF 다운로드
3. 완료 안내에서 바로 **[영문 이메일 제안문 복사]** → 메일 발송

5. 팀장 보고: 환율 시나리오 표 · 항목별 원가 표를 캡처

## 11. 일이 빨라지는 팁 모음

**입력**
1. **ERP 연동은 "되돌리기" 버튼이기도 합니다.** 이것저것 고치다 꼬였으면 [ERP 연동]을 다시 누르세요.
2. `ERP 값에서 수정됨`(주황)이 보이면 누군가 원가를 손댄 상태입니다. 견적서를 내기 전에 의도한 수정인지 확인하세요.
3. 1차 마진을 항목별로 관리하지 않는 품목은 **일괄**로 바꿔 한 칸만 관리하세요.
4. 바이어가 부자재를 직접 공급하면 **부자재 사급** 체크 한 번으로 부자재 마진이 0%가 됩니다.

**물류**
5. 품목 형태만 알면 **단품 용량/형태 프리셋**으로 물류비가 바로 나옵니다. 포장 사양이 다르면 입수·부피만 고치세요. 자동 반영은 유지됩니다.
6. 실견적을 받은 물류비는 **직접 입력** → 수량을 바꿔도 보존됩니다. 추정치로 돌아가려면 [물류비 자동 반영].
7. 마스크팩처럼 부피가 큰 품목은 1만개만 돼도 13 CBM입니다. 15 CBM을 넘으면 나오는 **FCL 안내**를 보고 컨테이너 견적과 비교하세요.

**협상**
8. 역제안 판정 순서대로 보세요: **판정 → 대응 방안 → (그래도 안 되면) VE·마진 조정.** 대부분은 대응 방안에서 끝납니다.
9. `○○개 유도` 카드는 "수량을 늘리면 이 가격이 된다"는 가장 설득력 있는 카운터 오퍼입니다.
10. **1차 마진 양보 한계치**는 사내 규정에 맞게 한 번 정해 두세요. 이 값이 🟠/🔴 경계(최대 양보가)를 정합니다.

**가격표 · 환율**
11. 할인 구간을 추가하면 그 수량 행이 자동으로 생깁니다. 따로 수량을 추가할 필요가 없습니다.
12. **견적 수량 추가**는 Enter로도 됩니다.
13. 장기 계약이면 환율 탭의 **방어 단가**를 근거로 "환율 ○○원 이하 시 단가 재협의" 조건을 견적서 비고에 넣으세요.
14. 기준 환율은 TTB보다 2% 낮게 잡혀 있습니다. 공격적인 가격이 필요할 때만 `TTB` 알약으로 실시간 값을 쓰세요.

**문서**
15. 견적서 형식은 팝업을 열기 **전에** 견적서 탭에서 고릅니다.
16. 팝업의 인코텀즈를 바꾸면 좌측도 바뀌어 단가가 다시 계산됩니다. PDF 직전에 인코텀즈를 바꿨다면 요약 줄의 합계를 한 번 더 확인하세요.
17. PDF 저장 후 팝업을 닫지 말고 바로 **영문 이메일 제안문 복사**까지 끝내세요. 같은 값이 들어갑니다.

**Q. 새로고침하면 입력한 값이 남나요?**
아니요. 이 도구는 **저장 기능이 없습니다.** 새로고침하면 기본값으로 돌아갑니다. 결과는 PDF · 가격표 복사 · 메일 복사로 남기세요.

**Q. 계산 결과를 믿어도 되나요?**
단가 계산식은 정확하지만, **물류비(CBM 추정)·VE 절감액·수량별 물류비 추정은 실무 약식**입니다. 최종 견적 전에는 포워더 견적·공급사 확인값으로 덮어쓰세요.

**Q. 같은 품목인데 동료와 단가가 다르게 나와요.**
기준 환율(자동값은 조회 시점 TTB에 따라 다름), 마진율/마크업 방식, 물류비 자동 반영 여부를 비교해 보세요.

## 13. 용어 정리

| 용어 | 뜻 |
|---|---|
| 1차 마진 | 원재료·임가공·부자재(와 물류비)에 각각 붙이는 마진. 제조 단계 마진 |
| 영업마진 | 1차 공급가 + 물류 공급가 위에 영업이 붙이는 마진 |
| 최소 영업마진 (방어선) | 최종 판매가 기준으로 절대 밑돌면 안 되는 영업마진 |
| 1차 마진 양보 한계치 | 역제안 때 항목별 1차 마진을 최대 어디까지 낮출 수 있는지 |
| 마진율 / 마크업 | 판매가 대비 / 원가 대비 마진 표기 방식 |
| 로스율 | 벌크 잔여·충진 파손 등 양산 손실. 원가에 곱해짐 |
| 사급 | 바이어가 부자재를 직접 공급. 부자재 마진 0% |
| 손익분기 | 원가 + 물류비만 회수하는 단가 |
| 최대 양보가 | 모든 1차 마진을 한계치까지 낮추고 최소 영업마진만 남긴 단가 |
| 최소 마진가 / 목표 마진가 | 최소 / 목표 영업마진을 지키는 단가 |
| TTB | 전신환 받으실 때 환율. 수출 대금을 원화로 바꿀 때 은행이 적용 |
| CBM | 부피 단위(㎥). 해상 LCL 운임·내륙 물류비의 기준 |
| LCL / FCL | 컨테이너 일부만 쓰는 혼재 화물 / 컨테이너 한 대 단독 |
| MOQ | 최소 주문수량 |
| VE | Value Engineering. 기능은 유지하며 사양을 바꿔 원가를 낮추는 방법 |
| R&R | 역할과 책임. 여기서는 마진 수준별 승인 권한 |
